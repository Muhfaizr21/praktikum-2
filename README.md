## 🚀 Cara Menjalankan

Proyek ini dibangun menggunakan HTML5 murni dengan CSS modern tanpa dependensi eksternal yang rumit. Untuk membukanya:

1. Klon repositori ini:
   ```bash
   git clone https://github.com/Muhfaizr21/praktikum-2.git
   ```
2. Masuk ke direktori:
   ```bash
   cd praktikum-2
   ```
3. Buka berkas `index.html` langsung pada peramban web (Google Chrome, Firefox, Safari, atau Edge) atau gunakan ekstensi *Live Server*.
